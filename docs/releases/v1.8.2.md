# BitChord Desktop — Revived v1.8.2

## Release Overview

**BitChord Desktop — Revived v1.8.2** is a major visual, usability, and platform compatibility update to the independently maintained native desktop client, introducing a redesigned interface, Spotify integration, Light Mode, improved navigation, native Arch Linux and CachyOS packaging, and extensive desktop refinements.

Building on the previous community release, v1.8.2 focuses on creating a more modern, cohesive, and customizable listening experience while preserving the original Kotlin/Compose desktop architecture.

### Based On & Comparison

This release continues the original [BitChord](https://github.com/kushagrasinghx/BitChord) project, developed by [@kushagrasinghx](https://github.com/kushagrasinghx).

The improvements below describe changes introduced in **BitChord Desktop — Revived since v1.8.1-revived.1**, rather than changes to the official upstream application.

**Version clarification:** `v1.8.2` belongs to the independently maintained community fork and is not an official upstream BitChord release.

## What's New

### Completely Redesigned Desktop Interface
- Introduced a refreshed desktop interface inspired by BitChord Web and Mobile.
- Redesigned the application layout with improved spacing, navigation, typography, and visual consistency.
- Added a modern floating bottom music player with updated playback controls.
- Redesigned the Search experience with integrated Explore content, music categories, and suggestions.
- Refined Home, Library, and other desktop pages for a more cohesive appearance.
- Updated player controls with SVG icons inspired by the original BitChord Web experience.
- Added configurable desktop UI scaling for different screen sizes and preferences.

### Light Mode & System Theme Support
- Introduced a complete Light Mode for the desktop application.
- Added **Follow System** as the default appearance option.
- Improved color contrast, typography, and surface separation throughout the interface.
- Updated lyrics, Replay, music lists, and playback controls to support Light Mode.
- Refined hover states, sliders, and secondary text for better readability.
- Preserved the original Dark Mode appearance while extending theme compatibility.

### Spotify Integration
- Introduced Spotify account integration for the desktop experience.
- Added Spotify content within the Library rather than a separate navigation tab.
- Added browser-based Spotify authentication.
- Added account management options under **Settings → Account & Integration**.
- Integrated Spotify library browsing with the existing desktop experience.
- Maintained YouTube Music as the playback backend for supported music playback.

### Improved YouTube Music Sign-In
- Added an integrated browser-based YouTube Music sign-in flow.
- Simplified the account connection experience.
- Improved consistency between YouTube Music and Spotify authentication interfaces.
- Refined account access and switching within the desktop sidebar.

### New Welcome Experience
- Added an animated welcome screen for first-time desktop launches.
- Introduced a streamlined onboarding experience with account connection options.
- Added automatic Light and Dark Mode compatibility.
- Improved welcome animation timing and transitions.
- Added per-installation first-launch detection, including portable installations.
- Existing account data no longer prevents the welcome screen from appearing on a fresh installation.

### Collapsible & Responsive Sidebar
- Introduced a collapsible desktop navigation sidebar.
- Added a compact icon-only navigation rail with tooltips.
- Automatically collapses the sidebar when the application window becomes narrow.
- Added a temporary overlay sidebar for compact window layouts.
- Preserved desktop-style navigation instead of switching to mobile bottom navigation.
- Consolidated account switching, navigation, and Settings access within the sidebar.
- Preserved sidebar preferences when resizing or reopening the application.

### Floating Music Player Improvements
- Introduced a redesigned floating bottom player as the default playback interface.
- Added an optional **Enable old top music player style** setting.
- Improved player positioning when resizing or maximizing the window.
- Added solid-background behavior when dynamic blur is reduced.
- Improved player spacing and clearance from scrolling content.
- Updated playback, shuffle, repeat, queue, and lyrics controls.
- Improved responsiveness of the classic top player in narrow windows.
- Preserved track information and essential playback controls across compact layouts.

### Windows 11 Mica & Visual Effects
- Introduced a wallpaper-tinted Mica-style sidebar on supported Windows 11 systems.
- Reduced unnecessary reflective effects in navigation surfaces.
- Replaced expensive sidebar glass effects with lighter rendering approaches.
- Improved visual consistency between expanded and collapsed sidebar states.
- Refined solid and translucent surfaces across supported appearance settings.
- Preserved native desktop window controls and system integration.

### Arch Linux & CachyOS Support
- Introduced native **Arch Linux and CachyOS package support**, extending compatibility to Arch-based Linux distributions.
- Added a dedicated **Pacman package (`.pkg.tar.zst`)** for native installation and package management.
- Integrated Arch package generation into the GitHub Actions release pipeline.
- Added automatic conversion of existing Debian build artifacts into native Arch packages, eliminating the need to recompile the application.
- Added native desktop launcher integration for KDE Plasma and other supported Linux desktop environments.
- Introduced an **AUR-ready `PKGBUILD`** with automated version-update preparation for future releases.
- Added SHA-256 integrity verification and automated Arch package validation.
- Preserved the original application binaries and bundled Java runtime for consistent functionality across supported Linux distributions.
- Enabled native installation and removal through the `pacman` package manager.

### Explore & Search Improvements
- Unified Explore and Search into a more consistent desktop browsing experience.
- Redesigned the Search landing page with music genres and mood categories.
- Improved search suggestions, keyboard focus, and result handling.
- Preserved Explore content while entering a search query.
- Automatically dismisses search suggestions when interacting outside the search field.
- Added an optional **Use old Explore cards** setting to restore the classic v1.7 visual style.
- Preserved the newer v1.8 Explore cards as the default appearance.

### Refined Scrolling & Transitions
- Introduced consistent top and bottom fading effects across desktop scrolling views.
- Expanded scroll fade behavior to Library, History, Downloads, Replay, Search, playlists, and other supported screens.
- Improved visual transitions between scrollable content and surrounding interface elements.
- Adjusted floating player positioning to maintain appropriate spacing.
- Made fade effects compatible with Light Mode, Dark Mode, and Follow System.
- Improved scrolling behavior for short lists and compact layouts.

### Arch Linux & CachyOS Installation

Download the `.pkg.tar.zst` package from the release assets and install it using Pacman:

```bash
sudo pacman -U ./bitchord-desktop-revived-bin-*.pkg.tar.zst
```

Once installed, BitChord Desktop — Revived can be launched directly from your desktop environment's application launcher.

**AUR Support:** An AUR-ready package configuration is included in the repository, with automated update preparation for future releases. Public AUR repository publication is planned separately.

## Release Notes

This release introduces substantial interface changes, so some visual and behavioral differences from earlier versions are expected.

The experimental fullscreen main-player feature was removed before this release to avoid a known Linux regression. It is not included in v1.8.2.

The separate experimental Rust rewrite is also not part of this release. BitChord Desktop — Revived continues to use the existing Kotlin/Compose architecture.

Some platform-specific functionality, including Mica effects, native window integration, and authentication behavior, may vary depending on the operating system and desktop environment.

Arch Linux and CachyOS packages use the same application binaries as the Debian distribution, repackaged for native Pacman compatibility. They are not separately compiled or optimized for CachyOS-specific CPU architectures.

Please report reproducible bugs through the repository's [GitHub Issues](https://github.com/Bntagaaa/BitChord-Desktop-Revived/issues) page.
