# Main player fullscreen icon attribution

The player fullscreen toggle follows the exact 18px glyph pairing used by
[BitChord Web's FullScreenPlayer](https://github.com/kushagrasinghx/BitChord/blob/main/web/app/src/shell/FullScreenPlayer.tsx):
`lucide-react` **Maximize** when windowed and **Minimize** when fullscreen.

- Vector source: [Lucide Maximize](https://github.com/lucide-icons/lucide/blob/main/icons/maximize.svg) and [Lucide Minimize](https://github.com/lucide-icons/lucide/blob/main/icons/minimize.svg).
- License: Lucide **ISC**.
- The SVG paths, viewBox, stroke width and rounded strokes are preserved.
  Only `currentColor` was replaced with white for Compose SVG resource support;
  the `Icon` tint provides the hover/normal alpha.
